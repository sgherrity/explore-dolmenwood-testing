        About This Tool

        This tool is built for Dolmenwood Referees running sessions involving overland hex travel. Select a hex to see what is visible around the party.

        Visibility Model

        Eye Level = Hex Elevation + Vantage Height. A neighboring hex is visible if your eye level ≥ that hex's elevation + its obstruction height.

        Obstruction heights by terrain:

        • Tangled / Boggy / Hilly / Open Forest — ~60′
        • Craggy Forest — ~40′
        • Fungal Forest / Swamp — ~20′
        • Bog, Farmland, Meadow, Hills, Water — none
        Vantage Height

        Adjust the Vantage (ft) field to raise your eye level above the hex elevation. Reset returns vantage to the default height.

        Prominent entries, which are highlighted in red, are tall enough to be seen above the canopy even when a hex would otherwise be obscured.

        Controls
        • Fog — limits visibility to only adjacent hexes.
        • Player — strips hex information and is intended for sharing with players.
        • World — shows or hides the full Dolmenwood world map.
        • 2D — flattens elevation so all hexes are treated as equal height.
        Saved Journeys

        Record the party’s journey across Dolmenwood. Click Track to start a new journey from the current hex. Click adjacent hexes to extend the trail. Click stop when finished.

        Each journey is stored with a name and date. From the Saved Journeys section you can:

        • Continue — resume adding hexes to the end of a journey.
        • Edit Origin — prepend hexes to the beginning of a journey.
        • Export / Import — back up tracks or share them between devices.

        Journeys are drawn on the world map and close-up map as a red line with waypoints marking the start and end of each journey.

        Capture

        The Capture button exports the hex graphic as a high-resolution PNG — useful for sharing a sightline snapshot with players or dropping into session notes.
